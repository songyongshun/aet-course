# 任务二：晶体管汽车电路的分析与测试

> **项目**：汽车执行器与控制电路的分析 · **学时**：4 · **教案编号**：10

## 学习目标

1. 理解共发射极基本放大电路的组成及工作原理
2. 掌握静态工作点的计算方法， 能通过直流通路分析电路的静态工作情况
3. 掌握动态性能指标 (电压放大倍数、 输入电阻、 输出电阻) 的计算
4. 理解静态工作点对输出波形的影响， 能判断饱和失真和截止失真
5. 能分析汽车电气线路搭铁探测器、 晶体管电压调节器等实际应用电路

## 一、共发射极基本放大电路的组成

### 电路组成

| 元件 | 作用 |
|------|------|
| **晶体管 VT** | 核心， 电流放大 |
| **偏置电阻** | 提供偏置与能量 |
| **控制电阻** | 控制基极电流 |
| **负载电阻** | 将电流变化转为电压变化 |
| **电容** | 隔直流通交流 |

## 二、静态工作点的分析与计算

### 直流通路画法

强调**电容视为断路**， 画出直流通路。

### 静态工作点计算

通过偏置电路计算基极电流和集电极电流：
$$I_B = \frac{U_{CC} - U_{BE}}{R_B}$$
$$I_C = \beta \cdot I_B$$

### 仿真验证

使用 Multisim 搭建电路， 测量静态值， 对比计算值与测量值。

## 三、动态性能分析

### 交流通路画法

**电容、 电源视为短路**。

### 微变等效电路

将晶体管简化为"**受控电流源 + 电阻**" 模型：

- 电压放大倍数： $A_v$ (负值表示输出信号与输入信号反相)
- 输入电阻： $R_{in}$
- 输出电阻： $R_{out}$

### 静态工作点对波形的影响

| 工作点位置 | 失真类型 | 原因 |
|----------|----------|------|
| 偏高 | **饱和失真** | 集电极电流饱和 |
| 偏低 | **截止失真** | 基极电流截止 |

**分压式射极偏置电路** 通过负反馈稳定静态工作点， 减小温度变化的影响。

## 四、实验操作

### 汽车电气线路搭铁探测器电路

1. **电路连接**： 识别晶体管 9013、 电解电容、 发光二极管引脚， 按电路图连接
2. **静态测试**： 用跨接线短接输入端， 测量 VT1、 VT2 的各极电位， 对比测量值与计算值
3. **动态测试**： 调节信号发生器输出 1kHz 正弦信号 (1mV/10mV/20mV)， 观察发光和发声变化

## 五、汽车电路应用

::: details 晶体管电压调节器 (JFT201 型)

分析电压调节器电路：
- 电压过高时 VT1 导通 → VT2 截止 → 励磁电流减小
- 电压过低时 VT1 截止 → VT2 导通 → 励磁电流增大
- 实现输出电压稳定

:::

::: details 转向灯闪光器

电容充放电控制 VT1 导通与截止， 实现转向灯闪烁：
- 电容充电期间 VT1 导通 → 灯亮
- 电容放电后 VT1 截止 → 灯灭
- 周期性循环实现闪烁

:::

## 教学设计

### 教学模式

**"任务驱动 - 理论讲解 - 实验验证 - 应用拓展"** 教学模式。

### 教学过程

1. **任务导入**： 汽车行驶中线路搭铁故障视频
2. **理论讲解**： "电路组成 → 静态分析 → 动态分析 → 失真与稳定"
3. **实验**： 搭铁探测器电路的连接、 静态测试、 动态测试
4. **应用拓展**： 晶体管电压调节器、 转向灯闪光器

## 总结与反思

学生掌握共发射极放大电路的组成与分析方法， 能进行静态与动态测试， 并分析晶体管在汽车电路中的应用。
