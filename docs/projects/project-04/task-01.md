# 任务一：晶体管的识别与检测

> **项目**：汽车执行器与控制电路的分析 · **学时**：4 · **教案编号**：9

## 学习目标

1. 明确晶体管的结构、 类型及图形符号， 能区分 NPN 型与 PNP 型晶体管
2. 理解晶体管电流分配关系和电流放大特性的原理
3. 掌握晶体管主要参数的含义及选用方法
4. 学会使用万用表检测晶体管引脚、 管型及质量

## 一、晶体管的结构、 符号及分类

### 晶体管的基本结构

晶体管 (三极管) 由三个区、 三个极、 两个结组成。

| 部分 | 结构 |
|------|------|
| **三个极** | 发射极 (E)、 基极 (B)、 集电极 (C) |
| **三个区** | 发射区、 基区、 集电区 |
| **两个结** | 发射结、 集电结 |

### NPN 型与 PNP 型

| 类型 | 结构 (从发射区→集电区) | 发射极箭头 |
|------|--------------------------|-------------|
| **NPN 型** | N - P - N | 箭头向外 |
| **PNP 型** | P - N - P | 箭头向内 |

::: details 晶体管实现电流放大的内部结构条件

- **发射区** 掺杂浓度很高， 以便有足够的载流子供 "发射"
- **基区** 做得很薄 (几个微米)， 掺杂浓度极低， 减少载流子复合
- **集电区** 体积较大， 掺杂浓度介于发射区和基区之间， 便于收集边缘载流子

> ⚠️ 双极型三极管并非是两个 PN 结的简单组合， **决不允许把发射极和集电极互换**。

:::

## 二、晶体管的电流放大作用

### 电流分配关系

晶体管电流满足： **$I_E = I_B + I_C$**

### 电流放大原理

- **发射结加正向电压**： 利于发射区电子扩散， 形成发射极电流 $I_E$
- 扩散电子的少数与基区空穴复合， 形成**基极电流 $I_B$**
- 多数继续向集电结边缘扩散， 形成**集电极电流 $I_C$**

**电流放大系数**： $$\beta = \frac{\Delta I_C}{\Delta I_B}$$

::: details 电流放大实验数据

当 $I_B$ 从 0.02mA 增至 0.03mA 时， $I_C$ 从 1.14mA 增至 1.74mA：
$$\beta = \frac{1.74 - 1.14}{0.03 - 0.02} = 60$$

基极电流控制集电极电流， 实现 "**小电流控制大电流**"。

:::

::: details 晶体管放大条件 (内外因)

- **内部条件**： 基区薄、 发射区掺杂浓度高
- **外部条件**： 发射结正偏、 集电结反偏

电位关系：
- NPN 型管： $V_C > V_B > V_E$
- PNP 型管： $V_C < V_B < V_E$

:::

## 三、晶体管的特性曲线

### 输出特性曲线

晶体管的输出特性曲线分为三个区域：

| 区域 | 特点 | 汽车应用 |
|------|------|----------|
| **放大区** | 线性放大， $I_C$ 随 $I_B$ 变化 | 音频放大电路 |
| **饱和区** | $I_C$ 不随 $I_B$ 明显变化 | 开关电路 |
| **截止区** | 基极电流为零， 输出截止 | 开关电路 (断开状态) |

晶体管作开关使用时候， 工作在**截止区或饱和区**； 作放大器使用时， 工作在**放大区**。

## 四、晶体管的主要参数

| 参数 | 含义 |
|------|------|
| **电流放大系数 β** | 集电极电流变化量与基极电流变化量之比 |
| **集电极最大电流 $I_{CM}$** | 集电极允许的最大电流 |
| **集电极最大功耗 $P_{CM}$** | 集电极允许的最大消耗功率 |

**选用**： 以汽车 ECU 中的功率放大电路为例， 依据集电极最大电流、 集电极最大功耗选择晶体管。 硅管 (9000 系列) 高温环境下性能优于锗管 (3AX 系列)。

## 五、晶体管管型与引脚的判别

### 引脚识记 (金属封装)

口诀： **"头向下， 左发右集"** — 俯视封装， 左为发射极， 右为集电极， 其余为基极。

### 万用表检测方法

1. **基极判别 (假设法)**： 用 R×1k 档， 假设某引脚为基极， 测量与其他两脚的正反向电阻。 基极应同时与其他两引脚存在类似对称的 PN 结电阻关系。
2. **管型判断**：
   - NPN 型： 黑表笔接基极时正向电阻小
   - PNP 型： 红表笔接基极时正向电阻小
3. **质量判断**： 反向电阻无穷大则正常 (无断路、 短路)。

::: details 检测步骤 - 指针式万用表

1. 连接表笔： 红表笔插 "+"， 黑表笔插 "COM"
2. 选择量程： 转到 R×1k 档
3. 测量正反向电阻， 判断管型、 材料 (硅/锗) 及好坏

:::

## 教学设计

### 教学模式

**"任务驱动 - 理论探究 - 实践验证"** 一体化教学模式， 以汽车电子维修中的晶体管故障检测为真实情境导入。

### 教学过程

1. **任务导入**： 发动机预热后电子模块不工作 → 晶体管损坏案例
2. **理论讲解**： "结构 → 原理 → 参数" 递进式， 动画演示载流子运动
3. **实践操作 (三级任务)**：
   - 基础层： 目视识别引脚
   - 进阶层： 万用表检测
   - 综合层： 电路仿真验证电流关系 ($I_E = I_B + I_C$)

### 标识回顾

晶体管识别三步骤： **看型号 → 测 PN 结 → 判引脚**。

## 总结与反思

学生能熟练使用万用表检测晶体管 (85% 以上小组能准确判断管型及引脚)， 电流放大原理仍需加强 Multisim 仿真动态演示。
