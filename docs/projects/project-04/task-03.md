## 一、集成运算放大器

### 集成运算放大器概述

集成运算放大器 (Op-Amp) 是一种包含多个晶体管和电阻等元件的高度集成化放大器。

### 理想运算放大器特性

| 特性 | 内容 |
|------|------|
| **输入电阻** | 无穷大 ($R_{in} = \infty$) |
| **输出电阻** | 为零 ($R_{out} = 0$) |
| **开环增益** | 无穷大 ($A_{OL} = \infty$) |
| **电压传输特性** | 线性区域工作 |

::: details 理想化条件

- 低频信号工作时可认为工作在线性区域
- 输入电阻很大 (可将输入电流近似为零)
- 输出电阻很小 (可将输出电压看为不受负载影响)

:::

### 引脚识别

- 识别集成运算放大器芯片的引脚 (电源、 接地、 输入/输出端)
- 使用万用表进行引脚测试

## 二、集成运算放大器的线性应用

### 同相放大电路

- 输出电压与输入电压同相
- 增益由电阻 R2/R1 决定

### 反相放大电路

- 输出电压与输入电压反相
- $U_o = -\frac{R_2}{R_1} \cdot U_i$

::: details 电压传输特性

输出电压与输入电压在**线性区域**成正比：
$$U_o = A_v \cdot U_i$$

当超过线性范围时， 输出饱和， 呈现非线性特性。

:::

## 三、集成运算放大器的非线性应用

- **比较器**： 比较两个输入信号大小
- **施密特触发器**： 具有滞回特性的触发器， 消除噪声干扰
- **窗口比较器**： 判断信号是否在特定范围内

::: details 窗口比较器

设置稳压管的稳定电压， 当输入信号电压位于上、 下边界之间时， 输出特定逻辑电平， 用于电压范围的检测。

:::

## 四、集成运算放大器在汽车中的应用

::: details 集成电路在汽车电压监视器中的应用

汽车充电系统电压监视器利用集成运算放大器监测充电电压：

- 电压正常范围内 → 输出正常信号
- 电压偏高或偏低 → 输出报警信号， 提醒驾驶员

:::

## 五、实验操作：电压监视器电路

### 电路分析

- 分析电压监视器电路组成
- 识别各元件作用

### 元件检测

- 检测晶体管、 电容等元件质量

### 电路搭建与调试

1. 按电路图搭建电压监视器电路
2. **静态测试**： 测量各节点电压电流， 判定静态工作情况
3. **动态调试**： 改变输入电压， 观察输出报警信号变化
4. **故障排查**： 找出电路故障点并修复
