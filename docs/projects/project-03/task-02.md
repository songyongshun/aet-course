# 任务二：汽车用变压器的原理分析与检测

> **项目**：汽车常用电磁器件原理分析与检测 · **学时**：6 · **教案编号**：8

## 学习目标

1. 掌握变压器的基本结构和工作原理
2. 掌握变压器的电压、 电流、 阻抗变换特性
3. 理解特殊变压器 (自耦变压器、 仪用互感器)
4. 理解变压器在汽车上的应用 (点火线圈)
5. 能进行点火线圈的故障检测

## 一、变压器的基本结构和工作原理

### 基本结构

| 部件 | 组成与作用 |
|------|-----------|
| **铁心** | 硅钢片叠压而成， 引导磁通 |
| **绕组** | 高压绕组和低压绕组同心地套在铁心上 |
| **其他部件** | 油箱、 冷却装置、 保护装置等 |

**类型**： 心式变压器、 壳式变压器

### 工作原理

变压器利用**电磁感应**原理， 在交流电路中改变电压、 电流和阻抗。

- 一次绕组通交流电 → 产生交变磁场 (磁通 Φ)
- 磁通经铁心耦合到二次绕组 → 感应电动势

## 二、变压器的特性

### 1. 电压变换

$$\frac{U_1}{U_2} = \frac{N_1}{N_2} = K$$

**K** 为变压比 (变比)。

### 2. 电流变换

$$\frac{I_1}{I_2} = \frac{N_2}{N_1} = \frac{1}{K}$$

### 3. 阻抗变换

$$Z_1 = K^2 \cdot Z_2$$

即二次侧阻抗折算到一次侧， 放大 $K^2$ 倍。

::: details 变压器能量守恒

变压器自身损耗很小， 输出功率 ≈ 输入功率：
$$U_1 I_1 \approx U_2 I_2$$

电压升高则电流降低， 电压降低则电流升高， 以保持功率平衡。

:::

## 三、特殊变压器

### 1. 自耦变压器

**特点**： 二次绕组是一次绕组的一部分

结构更紧凑， 效率更高， 但一次二次之间没有完全电气隔离。

**汽车典型应用**： **点火线圈**。

### 2. 仪用互感器

#### 电压互感器

- 高压绕组跨接在供电电路上， 低压绕组与电压表相连

::: danger 注意
电压互感器**测量时二次绕组电路不允许短路！**
:::

#### 电流互感器

- 一次绕组串联在电路中， 二次绕组与电流测量仪表相连

::: danger 注意
电流互感器**测量时二次绕组电路不允许开路！**

一次绕组工作电压较高时， 二次绕组与铁心必须接地。
:::

### 钳形电流表

利用电流互感器原理制作。 闭合铁心可张开， 将被测载流导线穿入铁心窗口内， 该导线相当于匝数为 1 的电流互感器一次绕组。 测量时**不用断开电路**， 使用非常方便。

## 四、汽车上使用的变压器

### 点火线圈

在汽车上应用最典型的自耦变压器是**点火线圈**， 它把汽车电源系统提供的低压变为高达几千伏甚至上万伏的高压， 用于点燃发动机内的汽油混合气。

**原理**： 一次、 二次绕组配合使用， 将汽车电源产生的低电压变为高电压， 形成稳定的电火花以点燃可燃混合气。

**分类**：
- **开磁路式点火线圈**： 两接线柱式、 三接线柱式
- **闭磁路点火线圈**： 日字形铁心， 含一次绕组接线柱、 二次绕组接线柱

### 点火线圈的故障检测

- 检测一次绕组、 二次绕组是否通断
- 检测绕组之间及绕组与铁心的绝缘电阻
