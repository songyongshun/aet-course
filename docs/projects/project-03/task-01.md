# 任务一：汽车用继电器的分析与检测

> **项目**：汽车常用电磁器件原理分析与检测 · **学时**：4 · **教案编号**：7

## 学习目标

1. 理解磁场的基本物理量 (磁通、 磁场强度、 磁化磁场)
2. 掌握电和磁的基本关系
3. 理解电磁铁、 继电器的结构和工作原理
4. 分析汽车上常见电磁部件的工作原理
5. 进行汽车上各种电磁铁、 继电器的故障检测

## 一、磁场的产生

### 磁体与磁性

- **磁性**： 物体能够吸引铁、 钴、 镍等物质的性质
- **磁体**： 具有磁性的物体

### 磁体的性质

1. 磁体两端磁性最强
2. **同名磁极互相排斥， 异名磁极互相吸引**
3. 原来没有磁性的铁磁物质放在磁铁旁获得磁性 (磁化)； 远离后保留一定磁性 (剩磁)

### 磁场

磁场具有**力和能** 的性质， 是磁体周围空间的一种特殊物质。 通常用**磁力线** 直观形象地表示磁场在空间各点的强弱和方向。

## 二、电和磁的关系

### 电流的磁场

- **直线电流的磁场**： 用右手螺旋定则判断方向
- **通电线圈的磁场**： 用右手螺旋定则 (安培定则) 判断方向

### 电磁感应

- 通电导线在磁场中受到力的作用 (电动机原理)
- 导体在磁场中运动产生感应电动势 (发电机原理)

## 三、磁路

磁通集中通过的**闭合路径** 称为磁路。

常见电工设备的磁路由铁心等磁性材料构成， 用于引导磁通。

## 四、铁磁性材料

### 铁磁性材料的磁性能

1. **高导磁性**： 外磁场作用下磁畴转向， 磁感应强度大大增加
2. **磁饱和性**： 外磁场增大到一定值时， 磁感应强度达到饱和
3. **磁滞性**： 磁感应强度 B 的变化总是落后于外磁场 H 的变化， 外磁场去除后产生**剩磁**

### 铁磁性材料的分类

| 类型 | 特点 | 应用 |
|------|------|------|
| **软磁材料** | 易磁化、 易去磁 | 发电机转子、 起动机转子、 继电器铁芯 |
| **硬磁材料** | 不易磁化也不易去磁 | 永久磁铁、 仪表 (电压表、 机油压力表) |
| **矩磁材料** | 小磁场即饱和， 磁性保持 | 计算机存储元件环形磁心 |

## 五、霍尔元件及在汽车中的应用

### 霍尔效应

将左手伸开， 让磁感应线穿过掌心， 四指指向控制电流方向， 大拇指所指方向就是**霍尔电压 $U_H$ 的正极**。

载流导体在磁场中受洛伦兹力作用， 在导体两端产生电势差 (霍尔电压)。

### 霍尔效应传感器 (转速传感器)

- 转子表面固定小磁铁， 霍尔元件设置在转子边
- 磁铁转到霍尔元件正面时输出电压， 转过后输出电压为零
- 转子每旋转一周， 输出一个脉冲 → 测出转速
- 转子与曲轴连接， 因此测出的转速就是**发动机转速**

## 六、电磁铁及在汽车上的应用

### 电磁铁

利用电磁力实现某一机械动作的电磁元件， 结构为： **线圈、 铁心、 衔铁**。

### 汽车上的电磁铁应用

::: details 盆形电喇叭

汽车盆形电喇叭由铁芯、 线圈、 衔铁、 膜片、 触点、 共鸣板组成。 线圈通电产生电磁吸力， 使膜片振动发声。

:::

::: details 汽车电控燃油喷射系统的喷油器

- 电磁铁中的衔铁与针阀一体
- 电磁线圈通电 → 电磁吸力吸引衔铁 → 针阀离开阀座 → 燃油喷射
- 电磁线圈断电 → 弹簧弹力使针阀关闭 → 喷油停止

:::

## 七、继电器及其在汽车上的应用

### 电磁式继电器

由**电磁机构** 和**触头系统** 组成， 结构和工作原理与接触器基本相同。

按吸引线圈电流分类： **直流电磁式继电器** 和 **交流电磁式继电器**。

电磁继电器是一种用控制电路中的**小电流或低电压** 控制**大电流或高电压** 的自动开关电器。

### 干簧继电器

- 线圈通入电流 → 轴向磁场 → 两干簧片磁化 → 触点极性相反 → 相互吸引闭合
- 线圈断电 → 磁场消失 → 干簧片靠弹性恢复原位 → 触点断开

### 汽车电喇叭继电器

利用开关控制继电器吸合与断开， 利用继电器触点控制电气部件的通断， 避免开关或按键无法承受大电流而烧毁。

## 八、继电器检测 (实验)

以电喇叭四脚继电器为例：

1. 用万用表测量**线圈电阻**： 判断线圈是否通断
2. 检测**触点吸合**： 通电测试触点是否正常闭合
3. 电路连接： 连接电喇叭电路， 测试继电器功能

## 教学设计

### 教学模式

**"任务驱动 - 理实一体化"** 教学模式， 以汽车喇叭继电器故障检测为教学情境。

### 教学过程

1. 故障案例导入： 汽车喇叭继电器故障
2. 磁场与电磁器件理论讲解
3. 继电器结构剖析与故障检测实践

### 实操项目

- 继电器检测 (线圈电阻、 触点吸合)
- 电路连接 (电喇叭电路)
- 使用器材： 万用表、 蓄电池、 继电器

## 总结与反思

学生能分析汽车上常见电磁部件的工作原理， 能进行汽车上各种电磁铁、 继电器的故障检测。
