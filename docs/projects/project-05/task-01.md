# 任务一：组合逻辑电路在汽车上的应用分析

> **项目**：数字电路及其在汽车上的应用 · **学时**：6 · **教案编号**：12

## 学习目标

1. 理解数字信号与模拟信号的区别， 能辨识汽车中的数字信号实例
2. 掌握常用逻辑门电路 (与门、 或门、 非门等) 的逻辑符号、 真值表及表达式
3. 理解组合逻辑电路的特点， 学会分析和设计简单组合逻辑电路的方法
4. 能识别常用集成门电路芯片的引脚及功能
5. 掌握组合逻辑电路在汽车中的典型应用 (如水位报警、 门锁控制)

## 一、数字信号

| 信号类型 | 特点 | 汽车应用 |
|----------|------|----------|
| **模拟信号** | 时间上和幅值上连续 | 冷却液温度传感器信号 |
| **数字信号** | 时间上和幅值上离散 (0/1 二值) | 曲轴位置传感器、 喷油器驱动信号 |

- 对模拟信号传输、 处理的电路 → **模拟电路**
- 对数字信号传输、 处理的电路 → **数字电路**

## 二、数制与码制

### 数制

#### 十进制

- 数码： 0~9； 基数： 10； 运算规律： 逢十进一
- 表示方法： $(255)_{10}$、 255D

#### 二进制

- 数码： 0、 1； 基数： 2； 运算规律： 逢二进一 ($1+1=10$)
- 表示方法： $(101)_{2}$、 101B
- 权展开式： $101_2 = 1\times2^2 + 0\times2^1 + 1\times2^0 = 5_{10}$

::: details 进制转换方法

**二进制 → 十进制**： 按权展开后相加 (将为 1 的位的位权直接相加， 更简便)

**十进制 → 二进制 (整数)**： 基数连除法 (除 2 取余)， 先得的余数为低位
例： 44 → 101100

**十进制 → 二进制 (小数)**： 基数连乘法 (乘 2 取整)， 先得的整数为高位
例： 0.375 → 0.011

**应用**： 汽车仪表显示转速 (十进制) 与传感器脉冲 (二进制) 的对应关系。

:::

### 码制

- **编码**： 按一定规律用数码来表示信息
- **二值编码**： 用二进制代码 0 和 1 表示特定数或文字
- **8421 码 (BCD 码)**： 最常用， 每位数用四位二进制表示

::: details BCD 码应用

汽车里程表 "123km" 的 8421 码表示： 0001 0010 0011

| 十进制 | 8421 码 |
|--------|----------|
| 0 | 0000 |
| 1 | 0001 |
| 2 | 0010 |
| 3 | 0011 |
| ... | ... |
| 9 | 1001 |

:::

## 三、常用逻辑门电路

### 基本逻辑关系

- **逻辑 1**： 真 (高电平)
- **逻辑 0**： 假 (低电平)

### 基本门电路

| 门 | 表达式 | 类比 | 全 1 规律 |
|----|--------|------|-----------|
| **与门** | Y = AB | 串联开关 | 全 1 出 1， 有 0 出 0 |
| **或门** | Y = A+B | 并联开关 | 有 1 出 1， 全 0 出 0 |
| **非门** | Y = ¬A | 单刀双掷开关 | 1 变 0， 0 变 1 |
| **异或门** | Y = A⊕B | 不同出 1 | 相同出 0， 不同出 1 |

### 复合门电路

- **与非门**： Y = ¬(AB)， 全 1 出 0， 有 0 出 1
- **或非门**： Y = ¬(A+B)， 全 0 出 1

::: details 集成门电路芯片

| 芯片 | 功能 |
|------|------|
| **74LS08** | 与门 |
| **74LS32** | 或门 |
| **74LS00** | 与非门 |
| **74LS04** | 非门 |
| **CD4069** | 六非门 |

:::

## 四、组合逻辑电路

由多个逻辑门组合成能实现一定功能的电路。

### 组合逻辑电路的分析方法

1. 由电路图写出逻辑表达式
2. 化简逻辑表达式 (公式法/卡诺图法)
3. 列出真值表， 分析电路功能

### 组合逻辑电路的设计方法

1. 根据功能要求列出真值表
2. 由真值表写出逻辑表达式
3. 化简逻辑表达式
4. 画出逻辑图

::: details 卡诺图化简 (三步法)

**"方格填 1 → 相邻合并 → 提取公因子"**：
- 相邻最小项合并， 画圈越大、 项越少， 电路越简化
- 对比化简前后电路复杂度， 强调 "圈越大、 项越少" 优化原则

:::

### 半加器

输入 A、 B， 输出为本位和以及进位：
- 半加器逻辑状态表体现加法的和与进位关系

### 编码器与译码器

- **编码器**： 将信息转换为编码
- **译码器**： 将编码还原为信息
- **三个二进制译码器**： 输出 8 种组合状态
- **七段译码显示器**： 用不同段发光显示数字

## 五、逻辑电路在汽车电路中的应用

### 汽车散热器水位报警器电路

- **组成**： CD4069 六非门芯片 (振荡器、 状态指示)、 铜棒探测器、 LED、 蜂鸣器
- **逻辑分析**：
  - 水位正常 (探测器导通)： 非门输入端低电平 → **绿色 LED 亮**
  - 水位过低 (探测器断开)： → **红色 LED 亮** + 振荡器起振 → 蜂鸣器报警

### 门锁控制电路

- 信号输入： 钥匙检测开关、 车门状态开关 (闭合为 1， 断开为 0)
- 逻辑判断： 当 "钥匙拔出 (1) 且车门关闭 (0)" 时， 与门输出 1 → 锁止信号
- 结合非门、 或门分析 "未关门时无法锁止" 的保护逻辑

## 教学设计

### 教学模式

**"理实一体化"** 教学模式， 以汽车实际应用为导向， 构建**"认知-分析-设计-实践"** 四阶教学流程。

### 教学过程

1. **情境导入**： 汽车故障视频 (水位报警失灵导致发动机过热)
2. **理论铺垫**： 对比模拟/数字信号， 过渡到逻辑门电路
3. **案例驱动**： 水位报警器、 门锁控制电路， 拆解为逻辑门组合单元
4. **实践强化**： 面包板、 集成芯片搭建汽车报警器

### 实操：水位报警器电路搭建

1. 识别 74LS04 芯片引脚： 14 脚 (VCC)、 7 脚 (GND)； 输入 (1、 3、 5、 9、 11、 13 脚)、 输出 (2、 4、 6、 8、 10、 12 脚)
2. 电路搭建： 探测器 (开关 S)、 LED、 蜂鸣器
3. 功能测试： 切换开关 S， 记录 LED 颜色和蜂鸣器状态

## 总结与反思

学生能准确描述与门、 或门的逻辑功能， 85% 学生可独立完成简单组合电路的真值表分析， 70% 小组成功搭建水位报警器。
