# 任务二：555 时基电路在汽车上的应用分析

> **项目**：数字电路及其在汽车上的应用 · **学时**：4 · **教案编号**：13

## 学习目标

1. 掌握常用触发器 (RS、 JK、 D 触发器) 的结构及逻辑功能
2. 理解 555 时基电路的内部结构、 工作原理
3. 能分析 555 电路构成的多谐振荡器、 单稳态触发器的工作特性
4. 掌握汽车转向灯闪光器、 防盗报警器等典型应用电路的分析方法
5. 通过实验操作， 培养电路搭建、 参数测试及故障排查的技能

## 一、触发器

触发器是数字电路中的时序逻辑元件， 具有**记忆功能**。

### 基本 RS 触发器

**特性表** (由与非门构成， 低电平有效)：

| R | S | Q<sub>n+1</sub> | 功能 |
|---|---|------------|------|
| 1 | 1 | Qn | 保持 |
| 1 | 0 | 1 | 置 1 |
| 0 | 1 | 0 | 置 0 |
| 0 | 0 | 不定 (禁止) | 非法 |

### 同步 RS 触发器

与基本 RS 触发器的区别在于使用受约束的输入状态， 避免非法状态。

### JK 触发器

- 具有特性方程， 比 RS 触发器更稳定
- **保持、 置 1、 置 0** 功能明确

### D 触发器

- 具有**延迟存储** 作用
- 汽车电子点火系统中的应用案例

::: details 触发器功能记忆 (卡片匹配法)

通过 "输入组合卡片 ↔ 输出状态卡片" 配对， 强化不同触发器的逻辑功能记忆。

:::

## 二、555 时基电路

### NE555 内部结构

拆解 NE555 内部框图： **三个 5kΩ 电阻、 两个比较器、 RS 触发器**。

### 工作原理

- 当阈值端 (6 脚) 电压 **> 2/3 U<sub>CC</sub>** 时 → 输出**低电平**
- 当触发端 (2 脚) 电压 **< 1/3 U<sub>CC</sub>** 时 → 输出**高电平**
- 通过 2/3 和 1/3 阈值电压控制输出状态的翻转

### 引脚功能

| 引脚 | 名称 | 功能 |
|------|------|------|
| 1 | 电源负极 | 接地 |
| 2 | 触发端 | < 1/3 U<sub>CC</sub> 时输出高电平 |
| 3 | 输出端 | 输出波形 |
| 6 | 阈值端 | > 2/3 U<sub>CC</sub> 时输出低电平 |
| 8 | 电源正极 | VCC |

## 三、555 电路的典型功能电路

### 多谐振荡器

- 输出为周期性方波
- **周期公式**： $T \approx 0.7(R_1 + 2R_2)C$
- 电容 C 通过 R1 充电， 通过 R2 放电

### 单稳态触发器

- 受触发后进入暂稳状态， 然后自动恢复
- **暂稳时间**： $t_w \approx 1.1 RC$

### 施密特触发器

- 具有滞回特性， 消除噪声干扰
- 应用于汽车前照灯自动变光器

## 四、555 时基电路的典型应用

### 汽车转向灯闪光器

- 利用 555 多谐振荡器产生周期闪烁信号
- **周期** $T \approx 0.7(R_1 + 2R_2)C$， 改变电阻 R2 可调节闪烁频率
- 二极管 VD1 的单向导电作用影响电容充放电时间

::: details 转向灯闪光器实操

1. 元件检测： 识别 NE555 芯片 8 脚 (电源)、 3 脚 (输出)； 检测 LED 正负极
2. 电路搭建： 按图接线， 区分继电器 K 的线圈引脚与触点引脚
3. 功能测试： 观察 LED1、 LED2 闪烁， 用示波器测量输出端 (3 脚) 波形周期

:::

### 汽车防盗报警

拆分为**触发、 延时、 报警** 三个模块：

- 触发模块检测入侵
- 延时模块提供缓冲
- 报警模块发出声光报警

### 汽车发动机转速表

利用 555 单稳态触发器测量转速：
- 转速信号触发单稳态， 暂稳时间 $t_w \approx 1.1RC$
- 将时间量转换为电流表读数

### 汽车前照灯自动变光器

利用 555 施密特触发器特性实现远近光自动切换。

## 教学设计

### 教学模式

**"岗课赛证"** 融合模式， 以汽车电子维修岗位需求为导向， 构建**"理论-仿真-实操-应用"** 四维教学体系。

### 教学过程

1. **理论**： "问题导入" (如 "汽车转向灯为何能周期性闪烁？")， 思维导图梳理逻辑关系
2. **仿真**： Multisim 搭建多谐振荡器、 单稳态触发器， 动态演示电容充放电波形
3. **实操**： 以汽车转向灯闪光器为项目载体， 完成元件识别、 电路搭建、 参数测试
4. **评价**： 过程性评价 + 成果性评价， 融入安全生产规范
