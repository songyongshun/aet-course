# 项目五：数字电路及其在汽车上的应用

> **所属模块**：数字模块 (Module 3) · **学时**：10 · **任务数**：2

## 项目概述

随着汽车电子技术的快速发展， **数字电路** 在汽车上的应用日益广泛， 包括发动机控制、 车身控制、 安全系统、 信息娱乐等领域。本项目学习数字电路的基本概念、 逻辑门电路、 组合逻辑电路和时序逻辑电路在汽车上的应用， 以及 **555 时基电路** 的工作原理和典型应用。

### 项目目标

通过本项目的学习， 学生将能够：

- ✅ 理解数字信号与模拟信号的区别
- ✅ 掌握常用数制（二进制、 十进制）及码制（8421、 格雷码）之间的转换
- ✅ 理解并应用各种逻辑门电路（与门、 或门、 非门、 异或门）
- ✅ 分析和设计组合逻辑电路
- ✅ 掌握基本 RS 触发器的结构和工作原理
- ✅ 理解 555 时基电路的结构和工作原理
- ✅ 分析 555 时基电路在汽车上的典型应用

## 相关知识

::: tip 数字信号 vs 模拟信号

| 类型 | 特点 | 汽车应用 |
|------|------|----------|
| **模拟信号** | 时间上和幅值上连续 | 音响、 传感器信号 |
| **数字信号** | 时间上和幅值上离散 | ECU 控制、 CAN 总线 |

:::

::: details 8421 码

**8421 码** (BCD 码) 是最常用的二进制编码制：

| 十进制 | 8421 码 |
|--------|----------|
| 0 | 0000 |
| 1 | 0001 |
| 2 | 0010 |
| 3 | 0011 |
| 4 | 0100 |
| 5 | 0101 |
| 6 | 0110 |
| 7 | 0111 |
| 8 | 1000 |
| 9 | 1001 |

:::

::: details 555 时基电路

**555 定时器** 是一种常用的可编制时基电路， 具有 8 个引脚：

| 引脚 | 名称 | 功能 |
|------|------|------|
| 1 | GND | 电源负极 |
| 2 | TRIG | 触发输入 (低电平触发) |
| 3 | OUT | 输出 |
| 4 | RESET | 复位 (低电平复位) |
| 5 | CONTR | -control 电压 |
| 6 | THR | 测时控制 |
| 7 | DISCH | 计时放电 |
| 8 | VCC | 电源正极 |

**典型应用**：
- 汽车转向灯闪光器
- 汽车防盗报警电路
- 发动机转速表

:::

## 教学方法

- **理论结合实践**： 逻辑门实验 + 555 电路搭建
- **案例驱动**： 以汽车水箱水位报警、 防盗报警电路为例
- **Multisim 仿真**： 验证逻辑电路的真值表
