# 任务二：汽车电路基本元器件的识别与检测

> **项目**：汽车直流电路的分析与测量 · **学时**：4 · **教案编号**：2

## 学习目标

1. 理解电阻、 电容和电感的特性及在汽车电路中的作用
2. 掌握电阻、 电容和电感的分类、 参数标注方法及检测步骤
3. 能熟练使用万用表对汽车常用电阻器、 电容器和电感器进行识读和质量检测
4. 能正确分析三种元器件在汽车电路 (如温度传感器、 点火系统) 中的应用案例

## 一、电阻元件的识别与检测

### 电阻的基础知识

电阻是描述导体对电流阻碍作用的物理量， 用字母 **R** 表示。

**单位换算**：
$$1MΩ = 1000kΩ = 1000000Ω$$

电阻器在电路中常用来进行电压、 电流的控制和传送， 起 **分压、 分流、 限流、 阻抗匹配** 等作用。

### 电阻器的分类

| 类型 | 特点 | 常见形式 |
|------|------|----------|
| **固定电阻** | 阻值固定 | 碳膜电阻、 金属膜电阻、 贴片电阻 |
| **可变电阻** | 阻值可调 | 电位器、 滑线变阻器 |
| **特殊电阻** | 阻值随敏感源变化 | 热敏电阻、 光敏电阻、 压敏电阻 |

### 特殊电阻及应用

::: details 热敏电阻 NTC/PTC

- **NTC** (负温度系数)： 阻值随温度升高而**减小**
- **PTC** (正温度系数)： 阻值随温度升高而**增大**

**汽车应用**： 进气温度传感器， 当进气温度低时， 热敏电阻阻值大， 信号电压高， ECU 控制增加喷油量； 温度高时， 阻值减小， 减少喷油量。

:::

::: details 光敏电阻

利用半导体的光电效应， 阻值随光照强度变化。

- 无光照射： 呈高阻状态
- 有光照射： 阻值迅速减小

**汽车应用**： 光电式光量传感器， 用于各种灯具亮灭的自动控制。

:::

::: details 压敏电阻

阻值对外界电压敏感， 电压增大时阻值迅速降低。

**应用**： 保护电路， 如电源电压突增时压敏电阻导通， 使保险丝熔断， 切断电源。

:::

### 电阻器的主要参数

1. **标称阻值和允许偏差**： I级 (±5%)、 II级 (±10%)、 III级 (±20%)
2. **额定功率**： 电阻长时间工作不损坏的允许最大功率
3. **温度系数**： 温度每变化 1℃ 所引起的电阻值相对变化， 用 α 表示

### 电阻器参数的标志方法

| 方法 | 说明 | 示例 |
|------|------|------|
| **直标法** | 直接标出主要参数 | 体积大的元器件用 |
| **文字符号法** | 数字与字母组合 | R47 → 0.47Ω， 2R2 → 2.2Ω |
| **数码表示法** | 三位数码： 前两位有效数字， 第三位为 10 的幂次 | 470 → 47Ω, 471 → 470Ω |
| **色标法 (色环法)** | 用色环表示阻值 | 四环、 五环电阻 |

::: details 色环电阻读法

**四环电阻**： 第一环 (十位) + 第二环 (个位) + 第三环 (倍乘数) + 第四环 (误差)

例： 白 (9) 红 (2) 黑 (0) 金 (±5%) → $92 \times 10^0 = 92Ω ±5\%$

**五环电阻** (精密)： 前三环为有效数字， 4、 5 环表示倍乘和误差

注意读取顺序： 靠近引线的色环为第一环； 最后一环与其它环间距较大。

:::

### 电阻器的检测

::: details 指针式万用表检测固定电阻

1. **连接表笔**： 红表笔插 "+" 孔， 黑表笔插 "COM"
2. **机械调零**： 水平放置， 调整指针到零位
3. **选择量程**： 预估阻值， 转到合适的 Ω 档 (如 ×100 或 ×1k)
4. **欧姆调零**： 短接表笔， 调节调零旋钮使指针指 0 (每换量程需重新调零)
5. **测量电阻**： 表笔跨接被测电阻两端 (手不能同时接触)
6. **读取**： 读欧姆刻度线读数 × 量程倍率

:::

::: details 数字式万用表检测固定电阻

- 使用前不用校零， 将档位转到适当的电阻档
- 若显示 "000" → 短路
- 若最高位显示 "1" → 断路
- 显示值偏离标示值很大 → 老化

:::

**各类电阻检测要点**：

- **可变电阻 (电位器)**： 旋转轴柄应平滑， 阻值逐渐平稳变化； 有跳动说明接触不良
- **热敏电阻**： 加温检测， 阻值随温度变化明显为良好
- **光敏电阻**： 用光源照射透光窗口， 阻值明显减小为良好
- **压敏电阻**： 在路检测， 电压升高阻值减小为良好

## 二、电容元件的识别与检测

### 电容器的基础知识

电容器是能够容纳和储存电荷的装置。

**电容量**： 电容器任一极板储存的电荷量 Q 与两板间电压 U 的比值。
$$C = \frac{Q}{U}$$

**单位**： 法拉 (F)， 常用 micro (μF)、 纳法 (nF)、 皮法 (pF)。

### 电容器的主要性能指标

| 指标 | 说明 |
|------|------|
| **标称容量和允许偏差** | I级 (±5%)、 II级 (±10%)、 III级 (±20%) |
| **额定电压 (耐压)** | 电容长期安全工作允许的最大直流电压 |
| **绝缘电阻** | 电容两极间电阻， 无极性电容 $10^8 \sim 10^{10}Ω$； 电解电容 200~500kΩ |

### 电容器的参数标志方法

| 方法 | 说明 | 示例 |
|------|------|------|
| **直标法** | 直接标注主要参数 | 25V 100μF |
| **数码表示法** | 三位数码， 前两位有效数字， 第三位为 10 的幂次 (pF) | 104 → $10 \times 10^4 pF = 0.1μF$ |
| **色码表示法** | 类似电阻色标法 | 色环表示容量 |

> 注意： 用数码表示法时， 第三位数码是 "9" 时表示 $10^{-1}$， 即 0.1×(前两位)

### 电容器的检测

- **指针式万用表**： 表针应向阻值小的方向摆动， 然后慢慢回摆； 摆幅越大电容量越大
- **数字式万用表**：
  - 电容档直接检测： 将已放电电容插入测试插孔， 比较读数与标称值
  - 电阻档测量 (0.1μF 以上)： 显示值从 "000" 逐渐增加， 显示溢出 "1" 为正常
    - 不断显示 "000" → 内部短路
    - 不断显示 "1" → 内部开路

### 电容器的充放电特性

- 充电： 开关接通 A 端， 电场力使电荷向电容器移动
- 放电： 开关拨到 B 端， 电容器通过电阻放电
- 电容器具有 **隔直流、 通交流** 的作用

## 三、电感元件的识别与检测

### 电感的基础知识

电感器是储能元件， 依据电磁感应原理， 由导线绕制而成， 具有 **通直流、 阻隔交流** 的作用。

当电感线圈通以电流时， 将产生磁通， 在其内部及周围建立磁场， 储存磁场能量。

### 电感的分类

| 分类方式 | 类型 |
|----------|------|
| 按电感量变化 | 固定电感、 微调电感、 可变电感 |
| 按导磁性质 | 空芯线圈、 磁芯线圈、 铜芯线圈 |
| 按用途 | 天线线圈、 扼流线圈、 振荡线圈 |
| 按耦合方式 | 自感应线圈、 互感应线圈 |

### 电感的主要性能参数

| 参数 | 说明 |
|------|------|
| **标称电感 L** | 线圈本身固有特性， 与电流大小无关 |
| **品质因数 Q** | $Q = \frac{X_L}{R}$， 感抗与等效电阻之比， Q 值越高品质越好 |
| **额定电流** | 允许通过的最大电流 |
| **分布电容** | 匝间、 屏蔽罩间的电容效应， 使 Q 值下降 |
| **直流电阻** | 电感线圈的直流损耗电阻 |

### 电感的标注方法

- **直标法**： 直接标注电感值、 额定电流 (字母 A~E) 和允许误差
- **文字符号法**： 小数点用 "R" 表示， 单位 μH (如 4R7 → 4.7μH)
- **数码法**： 三位数字， 默认单位 μH (如 470 → 47μH)
- **色标法**： 四色环， 单位 μH

### 电感的特性

电感器线圈中电流变化时， 产生自感电动势 $e_L$。**在直流电路中， 电感器相当于短路**。

### 电感器的检测

1. **外观检查**： 检查外形完好、 磁芯有无缺损、 线圈干燥等
2. **万用表测量**：
   - 用电阻档测线圈通断， 指针偏转说明线圈通 (良好)
   - 用 500V 兆欧表测绝缘电阻， 低于几兆欧说明绝缘受潮或击穿

## 教学设计

### 教学模式

**"任务驱动 - 理实一体化"** 教学模式， 以汽车转向灯不闪烁的故障案例为切入点。

### 教学过程

1. **任务导入**： 汽车转向灯不闪烁 → 电路组成、 元器件识别 → 检测
2. **特性对比**： 电阻 / 电容 / 电感的作用、 单位、 符号对比表
3. **参数识读**： 色环电阻竞赛、 电容数码法速算
4. **元器件检测**： 万用表检测电阻通断、 电容充放电、 电感绝缘电阻

## 总结与反思

通过识别与检测实践， 学生能掌握三种基本元件的特点测试方法， 并能在汽车电路 (温度传感器、 点火系统) 中正确分析。
