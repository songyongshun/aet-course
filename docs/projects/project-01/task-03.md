# 任务三：汽车电路的分析

> **项目**：汽车直流电路的分析与测量 · **学时**：4 · **教案编号**：3

## 学习目标

1. 掌握电路的通路、 断路、 短路三种状态的特点
2. 明确串、 并联电路的特点及在汽车上的应用
3. 熟记利用欧姆定律、 基尔霍夫定律、 支路电流法求解电路的方法
4. 会应用电路基本定律分析求解电路的基本物理量
5. 能根据电路特点进行简单故障排除

## 一、电路的三种状态

### 1. 通路 (正常工作状态)

指正常工作状态下的闭合电路。 开关 S 闭合， 电路中有电流和能量传输与转换。

**电路特征**：
- 电路中的电流为正常值
- 负载电压为额定值
- 负载消耗功率为额定功率

**额定值**： 电气设备铭牌标注的最大限值。 如 "220V、 40W" 电灯在 220V 下功率为 40W。
- 电气设备在额定值下工作 → **满载**
- 超过额定值 → **超载 (过载)**， 会引起损坏
- 低于额定值 → **轻载 (欠载)**， 不能充分利用设备能力

::: details 例题 1

一个 "220V/100W" 的灯泡正常发光时通过灯丝的电流是多少？灯丝的电阻是多大？

由 $P = UI$， 得 $I = \frac{P}{U} = \frac{100}{220} \approx 0.455A$

由 $P = \frac{U^2}{R}$， 得 $R = \frac{U^2}{P} = \frac{220^2}{100} = 484Ω$

若电源电压降为 210V， 灯泡不能正常发光。

:::

### 2. 开路 (断路状态)

开关 S 断开， 电路中没有电流流通， 电源处于空载运行状态。

**电路特征**：
- 电路中的电流为零
- 电源的端电压等于理想电压源电压
- 电源的输出功率和负载消耗功率均为零

**开路类型**：
- **控制性开路**： 根据需要利用开关断开电路 (如电灯开关)
- **故障性开路**： 突发性的断路状态 (如电气设备损坏)

::: details 用试灯寻找断路点

将试灯一端接在电源负极， 另一端依次触及电路接线点 a、 b、 c、 d。

- 试灯亮 → 该接线点至电源正极间无断路
- 试灯不亮 → 该接线点与前一接线点间有断路

用此方法逐步缩小故障范围， 直至找到断路点。

:::

### 3. 短路 (短路状态)

由于电源线绝缘损坏或操作不当等引起电源的两输出端相接触， 电流未经过负载经过短路点。

**电路特征**：
- 电路中的电流最大
- 电源和负载的端电压均为零
- 电源产生的功率全部消耗在电源内阻上

::: danger 短路故障不允许发生！

短路时电流极大， 会损坏电路设备。 但实际维修中可利用 **跨接线** 检测电路：

1. 将跨接线连在被测部件 "-" 端子与车身搭铁之间， 若部件工作， 说明接地线路断路
2. 若接地良好， 将跨接线连在蓄电池 "+" 极与部件 "+" 端子之间， 若部件工作， 说明电源电路有故障
3. 若部件仍不工作， 说明部件本身有故障

注意： 不可将跨接线错误地连在被测部件 "+" 端子与搭铁之间！

:::

## 二、电阻的连接

### 1. 电阻的串联

两个或两个以上的电阻顺次相连。

**特性**：
1. 串联电路电流处处相等： $I = I_1 = I_2 = \cdots = I_n$
2. 等效电阻等于各电阻之和： $R = R_1 + R_2 + \cdots + R_n$
3. 总电压等于各部分电压之和： $U = U_1 + U_2 + \cdots + U_n$
4. 每个电阻上的电压与电阻值成正比 (分压公式)：
   $$U_i = \frac{R_i}{R} \cdot U$$

::: details 串串联应用 - 电压表量程扩展

选用合适的电阻与表头串联， 可获得不同的量程， 制作多量程电压表。

**例**： 表头内阻 $R_g = 1000Ω$， 满偏电流 $I_g = 100μA$， 改装成 3V 电压表。

表头满偏电压： $U_g = I_g \cdot R_g = 0.1V$

分压电阻需分压： $U_R = 3 - 0.1 = 2.9V$

串联电阻： $R = \frac{U_R}{I_g} = \frac{2.9}{0.0001} = 29000Ω = 29kΩ$

:::

::: details 串联应用 - 汽车温度传感器

汽车温度传感器电路利用电阻串联分压特性：

- 冷却液温度传感器内热敏电阻 $R_{NTC}$ 与 ECU 内电阻 $R_C$ 串联分压
- 温度变化 → 热敏电阻阻值变化 → 分压电压 Uo 变化
- 作为燃油喷射和点火正时的修正信号

:::

### 2. 电阻的并联

两个或两个以上的电阻首尾相接在相同两点之间。

**特性**：
1. 各支路两端的电压相等： $U = U_1 = U_2 = \cdots = U_n$
2. 总电流等于各支路电流之和： $I = I_1 + I_2 + \cdots + I_n$
3. 等效电阻的倒数等于各分电阻倒数之和：
   $$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}$$
4. 每条支路电流与支路电阻成反比 (分流公式)：
   $$I_i = \frac{R}{R_i} \cdot I$$

::: details 例题 - 两电阻并联

已知 $R_1 = 3Ω$， $R_2 = 6Ω$， $U = 10V$。

① 等效电阻： $R = \frac{R_1 \cdot R_2}{R_1 + R_2} = \frac{18}{9} = 2Ω$

② 总电流： $I = \frac{U}{R} = \frac{10}{2} = 5A$

$I_1 = \frac{U}{R_1} = \frac{10}{3} \approx 3.33A$， $I_2 = \frac{U}{R_2} = \frac{10}{6} \approx 1.67A$

③ 总功率： $P = UI = 50W$， $P_1 = UI_1 \approx 33.3W$， $P_2 = UI_2 \approx 16.7W$

:::

::: details 并联应用 - 后窗除霜器

汽车后窗除霜器由若干条电热丝并联连接， 每条电热丝相当于一个电阻， 等效为多个电阻并联。

- 保证各电热丝承受额定电压
- 方便实现各分支电路的控制

:::

### 3. 电阻的混联

既有串联又有并联的电路称为混联电路。 利用电阻串并联关系可以逐步化简。

**分析方法**： 从内向外， 先化并联再化串联。

## 三、电路的基本定律

### 1. 欧姆定律

**部分电路欧姆定律**： 通过导体的电流与导体两端电压成正比， 与导体电阻成反比。
$$I = \frac{U}{R}$$

**全电路欧姆定律**： 考虑电源内阻， 闭合电路中的电流与电源电动势成正比， 与回路总电阻 (外电路电阻 + 内阻) 成反比。
$$I = \frac{E}{R + r}$$

### 2. 基尔霍夫定律

#### 基尔霍夫电流定律 (KCL)

**内容**： 在任一瞬间， 流入电路中任一结点的电流之和等于流出该结点的电流之和。

$$\sum I_{入} = \sum I_{出}$$

**数学表达式**： $\sum I = 0$ (流入为正， 流出为负)

**推广**： 任一瞬间通过任一封闭面的电流代数和也恒等于零 (广义结点)。

::: details 例题 4

已知 $I_1 = 4A$， $I_2 = -2A$， $I_3 = 1A$， $I_4 = -3A$， 求 $I_5$。

由 KCL： $I_1 + I_2 + I_3 + I_4 + I_5 = 0$

$4 - 2 + 1 - 3 + I_5 = 0$

$I_5 = 0$

:::

#### 基尔霍夫电压定律 (KVL)

**内容**： 在任一回路中， 沿任一回路绕行一周， 回路中所有电压降的代数和等于零。

$$\sum U = 0$$

**注意事项**：
1. 首先选定回路的绕行方向 (顺时针或逆时针)
2. 设定各元件上的电压参考方向
3. 与绕行方向一致的电压降取正， 否则取负

**推广**： 可应用到回路的部分电路 (广义回路)， 用于求回路的开路电压。

::: details 基本概念

- **支路**： 一或几个二端元件首尾相接， 中间无分岔 (支路数 m)
- **结点**： 三条或三条以上支路的汇集点 (结点数 n)
- **回路**： 电路中任意闭合路径
- **网孔**： 不包含其它支路的单一闭合路径 (回路不一定是网孔)

:::

### 3. 支路电流法

以支路电流为待求量， 直接应用基尔霍夫定律 (KCL + KVL) 求解支路电流的方法。

**步骤**：
1. 假定各支路电流、 电路元件电压的参考方向及回路绕行方向
2. 对结点列 KCL 方程 (n 个结点列 n-1 个独立方程)
3. 列回路 KVL 方程 (m 条支路列 m-n+1 个独立回路方程)
4. 代入数据， 求解联立方程组

::: details 例题 6 - 支路电流法

已知 $E_1 = E_2 = 62V$， $R_1 = 1Ω$， $R_2 = 2Ω$， $R_3 = 20Ω$， 求各支路电流。

节点 A（KCL）： $I_1 + I_2 = I_3$

回路 I（KVL）： $E_1 - I_1 R_1 - I_3 R_3 = 0$

回路 II（KVL）： $E_2 - I_2 R_2 - I_3 R_3 = 0$

代入数据求解联立方程组即可得各支路电流。

:::

## 四、惠斯通电桥及其在汽车上的应用

::: details 惠斯通电桥原理

惠斯通电桥由四个电阻组成桥式电路， 具有灵敏的测量特性。

当电桥平衡时 ($R_1 / R_2 = R_3 / R_4$)， 电桥对角线间 (电流表旁路) 没有电流通过。

在汽车热线式空气流量传感器中， 利用桥式电路将电阻变化转化为电信号。

:::
