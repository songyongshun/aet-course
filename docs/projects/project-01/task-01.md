# 任务一：汽车电路组成及基本物理量的分析与测量

> **项目**：汽车直流电路的分析与测量 · **学时**：4 · **教案编号**：1

## 学习目标

1. 了解汽车电路的基本结构， 包括电源、 负载、 中间环节的组成及作用
2. 明确汽车电路的特点： 低压直流供电、 单线制、 负极搭铁、 用电设备并联
3. 掌握电流、 电压、 电位、 电动势、 电功率等基本物理量的概念及计算方法
4. 学会使用万用表测量电流、 电压、 电阻和电位等基本电量
5. 能规范搭建简单汽车照明电路， 并进行故障分析与排除
6. 培养规范操作意识、 严谨科学态度及节约耗材的工作习惯

## 电路概述

### 汽车电路的组成

电路是电子元件与器件按照一定关系连接起来的通路。电流流经的路径称为电路。通常电路由 **电源**、 **负载** 和 **中间环节** (导线和开关) 等基本部分组成。

| 组成部分 | 作用 | 汽车常见实例 |
|----------|------|--------------|
| **电源** | 提供电能 | 蓄电池、 发电机 |
| **负载** | 消耗电能 | 车灯、 喇叭、  Showscreen |
| **中间环节** | 控制与保护 | 开关、 导线、 熔断器 |

### 电路的作用

1. **实现电能的传输与转换**： 电源 → 中间环节 → 负载， 传输电能并完成能量形式转换
2. **实现信号的传递与处理**： 信号源 → 信号处理 (放大、 调谐、 检波) → 负载

### 汽车电路的特点

::: tip 汽车电路的四大特点

1. **低压直流供电** (12V / 24V)
2. **单线制**： 通常只用一根导线连接电源正极和用电器， 电源负极端由车体金属部分代替
3. **负极搭铁**： 蓄电池负极接车架或车身， 称为负极搭铁。正极端引线为 "火线"， 负极端引线为 "搭铁线"
4. **用电设备并联**： 汽车上所有用电设备并联在电源上

:::

::: details 单线制 vs 双线制

**双线制** (家用电路)： 火线和零线都用导线连接， 两根导线一起连接负载。

**单线制** (汽车电路)： 只有 fire line (正极) 用导线连接， 而 zero line (负极) 通过车身作为公共回路。

优点： 节省导线、 减轻车重、 便于控制和保护

:::

### 理想电路元件

| 元件类型 | 电特性 | 符号 |
|----------|--------|------|
| **电阻元件** | 耗能 | R |
| **电容元件** | 储存电能 | C |
| **电感元件** | 储存磁能 | L |
| **理想电压源** | 恒压 | $U_S$ |
| **理想电流源** | 恒流 | $I_S$ |

## 基本物理量

### 1. 电流 (I)

- **定义**： 单位时间内通过导体横截面的电荷量
- **公式**： $I = \frac{q}{t}$
- **单位**： 安培 (A)
- **方向**： 正电荷定向移动的方向 (正电流方向)
- **类型**： 直流电流 (I)、 交流电流 (i)

::: details 电流方向

在金属导体中， 自由电子实际定向移动的方向与正电荷定向移动的方向**相反**。

:::

### 2. 电压 (U)

- **定义**： 电场力把单位正电荷从一点移动到另一点所做的功
- **单位**： 伏特 (V)
- **参考方向**： 用箭头或双下标表示 ( $U_{ab}$ 表示从 a 到 b 的电压)

**关联参考方向**： 电流从电压正极流入， 电压和电流同向

### 3. 电位 (V)

- **定义**： 电路中某一点与参考点之间的电压
- **参考点**： 电路中任意选定的一点， 规定该点的电位为零
- **关系**： 电压 = 电位差 ($U_{ab} = V_a - V_b$)

### 4. 电动势 (E)

- **定义**： 电源内部将单位正电荷从负极移到正极所做的功
- **方向**： 内部从负极指向正极 (低电位 → 高电位)
- **单位**： 伏特 (V)

### 5. 电功 (W) 和 电功率 (P)

- **电功**： $W = U \cdot I \cdot t$
- **电功率**： $P = \frac{W}{t} = U \cdot I$
- **单位**： 焦耳 (J)、 瓦特 (W)

::: details 例题

**例**： 一只 "12V / 5A" 的车灯， 功率为 $P = UI = 12 \times 5 = 60W$

:::

## 万用表使用方法

### 测量电流 (串联)

1. 将红表笔插入 "+" 孔， 黑表笔插入 "COM" 孔
2. 转到电流档 (A 或 mA)
3. **必须串联到电路中** (切断电路, 插入表笔)
4. 选择合适量程

### 测量电压 (并联)

1. 转到电压档 (V 或 mV)
2. **并联到电路中** (不切断电路)
3. 选择合适量程 (汽车 12V 电路: 选择 20V 档)

### 测量电阻 (断电)

1. **必须断电后测量**
2. 将电阻从电路中拆下 (至少焊开一端)
3. 转到欧姆 (Ω)档
4. 触碰导电部分 (不要用手同时接触)

## 教学设计

### 教学模式
**"任务驱动 - 理实结合"** 教学模式， 以汽车刮水器电路故障案例导入， 激发学生兴趣。

### 教学思路

1. **基础层** (元件检测) → 2. **进阶层** (电路搭建) → 3. **应用层** (参数测量与故障排除)

### 教学过程

#### 一、任务导入

播放汽车刮水器不工作故障视频， 提问： "电路由哪些部分组成？ 如何通过测量判断故障原因？"

#### 二、理论讲解

1. 电路组成与作用 (电源 / 负载 / 中间环节)
2. 汽车电路特点 (低压直流、 单线制、 负极搭铁、 并联用电)
3. 基本物理量 (电流、 电压、 电位、 电功率)

#### 三、实践操作

1. **元件检测**： 用万用表测试开关通断、 熔断器完好性、 电阻值
2. **电路搭建**： 断电操作 → 按图连接 → 确认后通电
3. **参数测量**： 测量电压、 电流， 以搭铁点为参考测量电位

#### 四、故障分析

设置 "熔断器熔断"、 "开关接触不良" 等故障场景， 学生通过测量判断原因并排除。

## 总结与反思

通过理论与实践结合， 学生掌握汽车电路的组成、 特点及基本物理量测量方法， 能独立完成简单电路的搭建与参数检测， 初步具备故障分析能力。

::: tip 常见问题
- **电位参考点的选择**： 电位值依赖于参考点， 电压值不变
- **万用表量程选择**： 预估量程 (如 12V 汽车电路选 20V 直流档)
- **线圈特性**： 电感线圈在直流电路中相当于短路
:::
