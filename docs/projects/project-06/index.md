# 项目六：新能源汽车的高压安全防护

> **所属模块**：高压模块 (Module 4) · **学时**：8 · **任务数**：2

## 项目概述

新能源汽车（电动汽车、 插电式混合动力汽车）使用 **高压电系统** 供电， 电压通常在 **300-650V** 之间。与传统汽车的 12V 低压系统不同， 新能源汽车的高压系统对维修人员的安全要求极高。掌握 **高压安全防护** 技术，是维修新能源汽车的基本要求。

### 项目目标

通过本项目的学习， 学生将能够：

- ✅ 了解高压电的等级划分和安全电压
- ✅ 明确新能源汽车高压电的特点和存在形式
- ✅ 掌握新能源电动汽车高压部件的作用
- ✅ 识别新能源汽车的高压安全标识
- ✅ 正确使用高压安全防护用具（绝缘手套、 安全帽、 护目镜）
- ✅ 熟练操作高压作业常用检测工具（钳形电流表、 绝缘电阻测试仪）
- ✅ 掌握高压作业的安全操作流程（先断电 → 再验电 → 后操作）

## 相关知识

::: tip 安全电压标准 (GB 18384-2020)

| 等级 | 直流电压 | 交流电压 | 风险等级 |
|------|----------|----------|----------|
| **A 级** | DC ≤ 60V | AC ≤ 30V | 轻度风险 |
| **B 级** | DC > 60V | AC > 30V | 严重风险 |

> 新能源汽车动力电池输出电压 (300-650V) 远超 B 级标准， 属于**高压**范围， 必须严格采取安全防护措施。

:::

::: details 新能源汽车高压系统主要部件

| 部件 | 作用 | 工作电压 |
|------|------|----------|
| **动力电池** | 存储能量， 输出高压直流 | 300-650V DC |
| **电机控制器 (逆变器)** | 直流转交流， 驱动电机 | 高压 DC → AC |
| **驱动电机** | 电能 → 机械能 | 三相高压 AC |
| **车载充电机 (OBC)** | 交流 → 直流， 给电池充电 | AC 220V → DC 300-650V |
| **高压配电箱 (PDU)** | 高压功率分配与保护 | 高压 DC |
| **DC/DC 转换器** | 高压 DC → 12V 低压 | 高压 → 12V |
| **高压线束** | 连接各高压部件 | 高压 |

:::

::: details 高压安全防护原则

1. **三必须**： 必须识别标识 → 必须穿戴用具 → 必须规范操作
2. **三步流程**： 先断电 → 再验电 → 后操作
3. **双人监护**： 高压作业必须有 1 名监护人在场， 手持应急断电设备
4. **7S 管理**： 对高压区域实行严格的管理规范

:::

## 教学方法

- **事故案例导入**： 播放新能源汽车高压触电事故新闻
- **VR 虚拟仿真**： 模拟高压部件操作， 降低实践风险
- **实车操作**： 比亚迪 e5 实车高压安全防护实操
- **标准讲解**： 结合 GB 18384-2020、 GB/T 17622-2008
