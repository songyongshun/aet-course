# 任务一：新能源汽车高压系统认知

> **项目**：新能源汽车的高压安全防护 · **学时**：4 · **教案编号**：14

## 学习目标

1. 了解高压电的等级划分和安全电压标准， 掌握 GB 18384-2020 中 A/B 级电压的划分
2. 明确新能源汽车高压电的特点， 包括直流/交流高压电的分布及存在形式
3. 掌握动力电池、 高压控制盒、 驱动电机等主要高压部件的名称及作用
4. 学会正确判断安全电压与危险电压， 能区分传统汽车与新能源汽车的电压差异
5. 能够在实车上识别高压部件位置

## 一、电压等级和安全电压

### 电压等级划分标准

| 标准 | 电压范围 |
|------|----------|
| **安全电压** | ≤ 36V |
| **低压** | ≤ 1kV |
| **高压** | > 1kV |
| **国际危险电压** | AC > 25V / DC > 60V |

### GB 18384-2020 电压等级

| 等级 | 直流电压 | 交流电压 | 风险 |
|------|----------|----------|------|
| **A 级** | DC ≤ 60V | AC ≤ 30V | 轻度 |
| **B 级** | DC > 60V | AC > 30V | 严重 |

::: danger 相对高压

新能源汽车动力电池实际输出电压 **300~650V**， 远超 B 级标准， 属于高压危险范围， 必须严格采取防护措施。

:::

## 二、电流与人体安全电流

### 人体安全电流

人体对电流的承受能力有限， 超过安全电流会危及生命。 电流通过人体会产生热效应、 化学效应和生理效应。

### 高压电特点

| 类型 | 分布 |
|------|------|
| **直流高压** | 动力电池 → 电机控制器 (300V)； 动力电池 → 电动压缩机 |
| **交流高压** | 充电口 → 车载充电机 (220V)； 电机控制器 → 驱动电机 (300V) |

### 高压电存在形式

| 存在形式 | 部件 | 条件 |
|----------|------|------|
| **持续存在** | 动力电池 | 无论车辆状态 |
| **运行期间存在** | 逆变器、 DC/DC 变换器 | READY 灯亮时 |
| **充电期间存在** | 充电口、 车载充电机 | 充电时 |

## 三、新能源汽车高压区域识别

### 主要高压部件

| 部件 | 作用 |
|------|------|
| **动力电池** | 能量存储核心， 输出高压直流电 |
| **高压控制盒 (PDU)** | 电源分配中心， 完成动力电池电源输出及分配， 保护分支电路 |
| **电机控制器 (逆变器)** | 高压直流逆变为三相交流， 驱动电机； CAN 通讯控制 |
| **驱动电机** | 电能 → 机械能， 支持再生制动 |
| **车载充电机 (OBC)** | 交流 → 直流， 给动力电池充电 |
| **DC/DC 转换器** | 高压直流 → 12V 低压 |
| **空调压缩机** | 高压电驱动、 压缩做功， 制冷采暖 |
| **高压线束** | 连接动力电池与每个高压负载 |

::: details 高压线束特征
- **橙色标记**： 高压线束统一采用橙色， 便于识别
- 含屏蔽层， 提供电磁屏蔽

:::

## 四、实验操作：实车高压部件识别

### 分组任务

每组 4 人， 使用比亚迪 e5 实车， 完成部件识别记录表。

### 操作步骤

1. **安全准备**： 佩戴绝缘手套， 确认车辆断电 (拔出维修开关)
2. **部件识别**： 按 "前舱 → 底盘 → 后备箱" 顺序查找高压控制盒、 动力电池、 驱动电机等 8 个部件
3. **功能匹配**： 描述各部件在能量传递中的作用 (如车载充电机将 AC 转为 DC)

### 教师指导重点

- 高压线束颜色识别
- 动力电池持续高压 (无论车辆状态)

## 教学设计

### 教学模式

**"任务驱动 - 理实结合"** 教学模式， 以 "售后维修高压部件识别" 真实场景为导向。

### 教学过程

1. **理论认知**： 标准解读、 案例分析、 电压等级与安全概念
2. **实车探究**： 比亚迪 e5 载体、 高压部件识别、 作用匹配
3. **评价反思**： 自评-互评-师评三维评价， 安全警示教育

### 高压存在形式思维导图

绘制 "高压存在形式思维导图"， 分析动力电池 (持续)、 驱动电机 (运行)、 充电口 (充电) 的电压存在条件。

## 总结与反思

学生能准确识别 80% 以上高压部件， 掌握 A/B 级电压划分标准； 90% 小组能规范执行断电流程。
