# 任务二：新能源汽车高压安全防护认知

> **项目**：新能源汽车的高压安全防护 · **学时**：4 · **教案编号**：15

## 学习目标

1. 明确新能源汽车高压安全标识的种类及识别方法
2. 掌握高压安全防护用具 (绝缘手套、 安全帽、 护目镜等) 的正确穿戴及检查流程
3. 熟练操作高压作业常用检测工具 (钳形电流表、 绝缘电阻测试仪)
4. 培养安全操作意识， 能在模拟维修场景中独立完成防护用具穿戴与工具使用
5. 了解新能源汽车高压系统的基本防护标准， 如 IP67 防护等级

## 一、高压安全标识

### 高压警示标识

- **黄色警示标识**： 黄色底色 + 黑色闪电图案， 国际标准
- **红色警示标识**： 用于更严重的危险场景

### 高压警示颜色

新能源汽车高压部件壳体、 高压线束统一采用特征标记：

- **橙色线束**： 工作电压 **> DC60V / AC30V**
- 维修时**禁止触碰未绝缘的橙色部件**

::: details 高压警告标识分布位置

- 高压部件外壳 (动力电池、 电机控制器、 PDU、 OBC、 空调压缩机壳体) → 黄色高压警示三角标识
- 高压线束与接插件 → 橙色专用绝缘外皮
- 机舱内部高压总成盖板、 保险盒 → 高压警告贴纸
- 车身充电口区域 → 高压警示 + 充电互锁防护
- 底盘动力电池包底部 → 防护挡板、 绝缘护板
- 高压维修开关 (MSD) 位置 → 明显警示标识

:::

## 二、高压安全防护用具

### 绝缘手套

- **分级选择**： 依据 GB/T 17622-2008
  - 0 级 (380V 以下) 至 4 级 (35kV 以下)
  - 1 级 (3kV 以下)、 8 级、 12 级、 20 级、 35kV 级
- **气压检测法**： 捏紧袖口挤压检查漏气
- **有效期**： 佩戴前检查生产日期 (有效期 2 年)

### 绝缘鞋

- 依据 GB 21146-2007 标准生产， 电阻值范围 100kΩ ~ 1000MΩ
- 应具有透气性好、 防静电、 耐磨、 防滑等功能
- 检查鞋底磨损情况 (花纹深度 ≥ 1.6mm)

### 护目镜

- 防止维修时电火花对眼睛的伤害
- 防止电池液飞溅

### 安全帽

- 保护头部免受跌落物体或碰撞伤害

### 防护服 (工作服)

- **必须穿非化纤类工作服**： 化纤会产生静电； 火灾时化纤高温粘连人体皮肤
- 防止电弧伤害

## 三、高压作业常用检测工具

### 绝缘工具

维护高电压类车辆时使用， 可有效防止意外触电事故。

### 钳形电流表 (电流钳)

- **优点**： 无须断开电源和线路即可直接测量运行中设备的工作电流
- **使用注意事项**：
  - 校零： 短接表笔读数 < 1Ω
  - 量程选择： 交流 600A 档
  - 单根线缆测量技巧： 避免同时钳入多根线缆产生相位误差

### 绝缘电阻测试仪

- 用于测量绝缘电阻， 保证电气系统安全
- **操作流程**：
  - 开路测试 (≥ 11GΩ)
  - 短路测试 (0Ω)
  - 500V 测试电压下绝缘地垫合格标准： ≥ 11GΩ

### 接地电阻测量仪

- 用于电力、 邮电、 铁路等部门测量装置接地电阻
- 也可测量低电阻导体电阻值、 土壤电阻率及地电压

## 四、高压作业安全规范

### 高压存在类型识别

| 类型 | 说明 |
|------|------|
| **持续存在** | 动力电池 (无论车辆状态) |
| **运行期间** | 逆变器、 DC/DC (READY 灯亮时) |
| **充电期间** | 充电口、 车载充电机 (充电时) |

### 电容残留电压的安全处理

- 结合电容放电原理， **维修前放电**
- 放电时间**不少于 1 分钟**

### 高压作业 "三必须"

1. **必须识别标识**
2. **必须穿戴用具**
3. **必须规范操作**

### 高压作业 "双人监护制"

- 操作时必须有 **1 名监护人在场**
- 监护人手持**应急断电装置**

## 教学设计 (四阶段教学)

1. **事故案例导入**： 播放新能源汽车维修触电事故案例， 引发安全意识
2. **理论分层讲解**： "标识识别 → 防护用具 → 检测工具"， 结合国际标准与国标
3. **虚拟仿真训练**： VR 软件模拟高压部件操作， 选择正确等级手套和绝缘鞋
4. **实车操作验证**： 比亚迪 e5 绝缘地垫测试、 电机电流测量

### 高压作业完整流程

**绝缘地垫铺设 → 防护用具穿戴 → 仪器校准 → 数据测量**， 教师全程录像回放纠错。

## 总结与反思

通过 VR 仿真与实车操作结合， 有效降低高压实操风险， 学生工具使用熟练度提升显著。
