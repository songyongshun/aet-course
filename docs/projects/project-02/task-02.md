# 任务二：汽车交流发电机的拆解与检测

> **项目**：汽车电源交流电路的分析与测量 · **学时**：4 · **教案编号**：5

## 学习目标

1. 理解汽车交流发电机的基本结构， 包括定子、 转子、 整流器等核心部件的组成及功能
2. 掌握交流发电机的工作原理， 能解释三相交流电的产生及整流过程
3. 熟练运用万用表等工具， 对定子绕组、 转子绕组及硅整流管进行规范检测
4. 能独立完成发电机的拆解与组装操作， 遵循安全操作规程和 7S 管理要求
5. 掌握触电危害及急救措施， 具备电气安全防护意识和应急处理能力

## 一、汽车交流发电机的结构

根据 **电磁感应** 原理， 交流发电机将发动机的机械能转换为电能。

### 核心部件

| 部件 | 组成 | 关键特征 |
|------|------|----------|
| **定子** | 三相绕组， 星形联结 | 固定部分， 产生三相交流电动势 |
| **转子** | 爪极式磁极 | 旋转磁场源， 通常为 6 对磁极 |
| **整流器** | 6 管桥式电路 (3 正 3 负) | 将交流电转换为直流电 |
| **端盖/风扇** | — | 支撑与散热 |

::: details JF 系列发电机拆解顺序

拆解流程： **带轮 → 前端盖 → 定子 → 转子 → 整流器**

- 使用拉马器取带轮， 注意标记安装位置
- 对称拧下固定螺栓， 避免端盖变形
- 记录电刷架弹簧朝向， 防止部件丢失

:::

## 二、汽车交流发电机的工作原理

### 三相交流电的产生

转子旋转产生旋转磁场， 切割定子三相绕组， 在三相绕组中产生**三相对称交流电动势**。

**励磁过程**：
1. **他励**： 点火开关接通时， 蓄电池提供励磁电流
2. **自励**： 转速升高 (约 1000r/min) 后， 发电机自行供电励磁

### 整流过程

三相桥式整流器将三相交流电转换为**直流电**给蓄电池充电。

## 三、安全用电常识

::: danger 触电急救

**触电方式**： 单相触电、 两相触电、 跨步电压触电

**安全电压**： 36V 以下为安全电压界限

**急救流程**： 断电 → 脱离电源 → 胸外按压。
1. 发现有人触电， 立即切断电源
2. 用绝缘物体使触电者脱离电源
3. 进行心肺复苏 (胸外按压)
4. 呼叫急救

:::

::: details 单相触电

在人站立位置进行单相触电时， 电流从带电导体经人体流向大地。 站在干燥绝缘物上可防止单相触电。

:::

## 四、发电机部件检测

### 转子绕组检测

- 测量滑环间电阻： **标准值 2-4Ω**
- 检测绝缘电阻： 要求 **>25MΩ**

### 定子绕组检测

- 测量三相绕组两两间电阻： **偏差 ≤ 0.5Ω**
- 铁芯绝缘电阻： **>25MΩ**

### 整流管检测

- **正极管**： 压装在散热板 (红色标记)
- **负极管**： 焊接在后端盖 (黑色标记)
- 判断标准： 正向导通、 反向截止

## 五、实验操作

### 工具认知

- 专用拆解工具： 拉马、 套筒扳手
- 万用表： 设置电阻档、 校零
- 绝缘手套： 检查密封性

### 分组分工

4 人一组， 明确角色： **主拆手、 记录员、 安全员、 质检员**。

### 组装与调试

1. 按拆解逆序组装， 检查转子转动灵活性
2. 模拟装机测试： 连接蓄电池， 测量输出电压 (怠速 13.5-14.5V)

## 教学设计

### 教学模式

**"任务驱动 - 理实一体化"** 教学模式， 以全国职业院校技能大赛 "汽车故障检修" 模块 B 赛项为导向， 构建**"认知-拆解-检测-组装-评价"** 五阶段教学流程。

### 教学特点

- 理论教学： 通过 "故障案例导入" + 结构剖视模型 + 动态原理图
- 实操教学： "基础操作-故障模拟-综合考核" 三级训练
- 使用带故障预设的发电机 (转子绕组短路、 整流管击穿)

### 评价体系

- 过程性评价： 7S 管理、 安全规范
- 结果性评价： 检测数据准确性、 故障判断正确率
- 引入企业技师参与技能考核

## 总结与反思

学生基本掌握发电机拆解流程 (达标率 85%)， 但整流管检测的正反向判断错误率仍达 20%， 需增加专项练习。
