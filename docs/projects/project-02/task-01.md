# 任务一：正弦交流电路的分析与测量

> **项目**：汽车电源交流电路的分析与测量 · **学时**：4 · **教案编号**：4

## 学习目标

1. 了解正弦交流电的概念及三要素 (最大值、 角频率、 初相)
2. 明确电阻、 电容和电感在交流电路中的电压电流关系及功率特性
3. 掌握三相交流电路的星形 (Y) 和三角形 (Δ) 连接方式及电压电流关系
4. 学会使用万用表、 示波器测量交流电压的有效值、 峰峰值、 周期和频率
5. 能对单一元件交流电路和对称三相电路进行基本参数计算

## 一、正弦交流电

大小和方向随时间按**正弦规律**变化的电流或电压统称正弦交流电。

### 表征正弦交流电的物理量

| 物理量 | 符号 | 说明 |
|--------|------|------|
| **周期** | T | 正弦量变化一个循环需要的时间 (s) |
| **频率** | f | 每秒完成循环变化的次数 (Hz) |
| **角频率** | ω | 每秒经历的弧度 (rad/s) |

**三者关系**：
$$\omega = 2\pi f = \frac{2\pi}{T}$$

> 我国电网交流电频率为 **50 Hz** (工频)。

### 正弦量三要素

确定一个正弦量必须具备三个要素：
1. **最大值 (幅值)** $I_m$ 或 $U_m$
2. **角频率** ω
3. **初相位** φ

### 瞬时值、 最大值和有效值

- **瞬时值** ($i$, $u$)： 任一时 t 刻对应的值
- **最大值** ($I_m$, $U_m$)： 最大瞬时值
- **有效值**： 与交流电热效应相同的直流电数值

有效值与最大值关系：
$$I = \frac{I_m}{\sqrt{2}} \approx 0.707 I_m$$

> 工程上所说交流电大小均指有效值。 如 220V 交流电压， 其最大值约为 311V。

### 相位、 初相和相位差

- **相位角** $(\omega t + \phi)$： 决定正弦量在某一瞬间的状态
- **初相** $\phi$： 计时始 $t=0$ 时的电角度， 规定 |φ| ≤ 180°
- **相位差**： 两个同频率正弦量初相之差

::: details 相位差名词

只有同频率的正弦量之间才有相位差概念：
- **同相**： φ = 0
- **反相**： φ = 180°
- **电流超前电压** / **电流滞后电压**： 相位差在 ±180° 之间

:::

## 二、单一元件正弦交流电路的特性

### 纯电阻电路

- 电压电流**同相位**
- 有功功率： $P = UI = I^2R$

### 纯电感电路

- **电压超前电流 90°** (π/2)
- 感抗： $X_L = 2\pi f L$
- 无功功率： $Q_L = UI$
- 特性： **通低频、 阻高频**

### 纯电容电路

- **电流超前电压 90°** (π/2)
- 容抗： $X_C = \frac{1}{2\pi f C}$
- 无功功率： $Q_C = UI$
- 特性： **通高频、 阻低频**

::: details 感抗、 容抗的频率特性

- **电感**： 频率越高， 感抗越大， 阻碍作用越强 → 通低频阻高频
- **电容**： 频率越高， 容抗越小， 阻碍作用越弱 → 通高频阻低频

设计阶梯频率实验 (50Hz → 5000Hz)， 让学生观察不同频率下的电流变化， 总结上述规律。

:::

## 三、三相交流电路

### 三相电源的连接

#### 星形连接 (Y)

将发电机三相绕组的末端 U2、 V2、 W2 接成一点 (中点 N)， 始端 U1、 V1、 W1 作为与外电路连接的端点。

**三相四线制**： 三条火线 + 中线 (零线)

**电压关系**：
- 相电压： $U_p$ (每相绕组两端电压)
- 线电压： $U_L$ (两条火线间电压)
- $U_L = \sqrt{3} \cdot U_p$， 线电压超前相应相电压 30°

::: tip 例
若相电压 220V， 则线电压 $U_L = \sqrt{3} \times 220 \approx 380V$。
:::

#### 三角形连接 (Δ)

三相绕组首尾依次相连， 构成三角形回路。

**特性**： 三相线电压即为三相相电压： $U_L = U_p$

### 三相负载的连接

#### 负载的星形连接

- 各相负载电流： 相电流
- **中线电流**： 三相负载对称时 $I_N = 0$， 对称星形负载可除去中线 (三相三线制)
- **不对称负载**： 中线有电流， 中线**不能被除去**， 否则会造成负载上三相电压严重不对称， 使用电设备不能正常工作

::: danger 重要安全规范

在三相不对称负载的星形联结中， **中性线不准安装熔断器和开关**。 中线用于平衡各相电压， 防止设备损坏。

:::

#### 照明电路实例

每组灯相互并联， 分别接至各相电压上。 当有中线时， 每组灯数量可以相等也可以不等， 但每盏灯上都可得到额定的 220V 工作电压。

## 实验操作

### 单相交流测量

用万用表测量电源电压有效值， 示波器读取峰峰值、 周期和频率。
$$U_{pp} = 2\sqrt{2}U$$

### 三相交流测量

测量三相电源相电压和线电压， 验证 $U_L = \sqrt{3}U_p$。

### 三相负载实验

1. **对称星形负载**： 有中线时观测各相电压对称， 断开中线观察变化
2. **不对称星形负载**： 更换一相灯泡， 测量有/无中线时的中点位移电压， 分析中线作用
