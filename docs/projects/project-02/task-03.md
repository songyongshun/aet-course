# 任务三：汽车整流电路的分析与测量

> **项目**：汽车电源交流电路的分析与测量 · **学时**：4 · **教案编号**：6

## 学习目标

1. 掌握二极管的结构、 特性及检测方法， 能使用万用表判断其极性和质量
2. 理解整流电路的工作原理， 包括半波、 桥式整流电路的组成与波形转换过程
3. 掌握汽车交流发电机整流器的电路结构， 能分析三相桥式整流的工作流程
4. 学会使用示波器观察整流电路的输入输出波形

## 一、半导体与二极管

### 半导体基础

半导体导电能力介于**导体与绝缘体**之间。

- **本征半导体**： 纯净半导体， 含自由电子与空穴
- **P 型半导体**： 掺杂 (如掺硼)， 空穴为多数载流子
- **N 型半导体**： 掺杂 (如掺磷)， 电子为多数载流子

### PN 结

P 型半导体与 N 型半导体结合形成 PN 结， 具有**单向导电性**。

- **正向偏置** (P 接正、 N 接负)： 内电场被削弱， 导通
- **反向偏置** (P 接负、 N 接正)： 内电场增强， 截止

### 二极管

二极管由 PN 结加上电极引出线构成， 具有**单向导电性** (整流、 检波、 稳压等作用)。

| 特性 | 说明 |
|------|------|
| **死区电压** | 硅管约 0.5V， 超过该值电流明显增大 |
| **正向往导通** | 外加正向电压， 阻值小 |
| **反向截止** | 外加反向电压， 阻值无穷大 |
| **反向击穿** | 反向电压过大击穿 PN 结 |

### 二极管极性检测

使用指针式万用表 **R×1k 档** 测量正反向电阻：

- 正向导通 (硅管 0.5-0.7V)： 阻值小
- 反向截止： 阻值无穷大

## 二、整流电路的工作原理

整流电路利用二极管单向导电性将交流电转换为直流电。

### 半波整流

- 二极管在交流电**正半周导通**， **负半周截止**
- 输出为单向脉动的直流电
- **不足**： 只利用一半波形， 利用率低

### 桥式整流 (全波整流)

使用四个二极管组成桥式电路， **电流路径法** 分析：

- **正半周**： VD1、 VD3 导通
- **负半周**： VD2、 VD4 导通

输出电压提高至半波整流的两倍， 波形更平滑。

### 三相桥式整流

汽车发电机整流器中 **6 个二极管 (3 正 3 负)** 将三相交流电转换为 **12V 直流电**。

- 三相交流电一个周期分为 6 个区间， 对应不同二极管导通组合
- 输出波形纹波更小， 更平滑

## 三、汽车整流电路

### 整流电路的作用

汽车发电机产生三相交流电， 经过整流后转换为直流电给蓄电池充电， 并为汽车电器系统供电。

### 整流电路的故障诊断

::: details 常见故障排查 (故障树)

| 故障现象 | 可能原因 |
|----------|----------|
| 输出电压为 0 | 二极管短路 |
| 波形畸变 | 二极管断路 |
| 纹波增大 | 滤波电容失效 |

排查流程： **测量 → 分析 → 验证**

:::

## 四、实验操作

### 二极管检测

使用万用表判断二极管极性及质量好坏。

### Multisim 仿真

- 搭建半波、 桥式整流电路
- 观察参数变化对输出波形的影响
- 对比理论计算与仿真结果

### 实操训练

- 二极管检测、 整流电路焊接、 波形测量
- 使用示波器记录半波/桥式电路输入输出波形

### 故障模拟

- 模拟二极管断路故障
- 训练学生使用万用表进行故障定位

## 教学设计

### 教学模式

**"理实一体化"** 教学模式， 以汽车发电机不发电的真实故障案例导入， 通过**"认知-仿真-实操-应用"** 四阶段展开教学。

### 教学过程

1. **理论认知**： 半导体基础知识、 二极管特性、 整流电路原理
2. **虚拟仿真**： Multisim 中搭建整流电路， 观察波形
3. **实操训练**： 二极管检测、 整流电路焊接与波形测量
4. **工程应用**： 拆解整流板， 分析三相整流原理， 模拟故障诊断

### 教学安全

- 融入安全教育 (如电容放电操作) 和 7S 管理规范

## 总结

学生掌握二极管单能导电性， 理解整流电路原理， 能完成整流电路的连接、 检测及故障排除。
