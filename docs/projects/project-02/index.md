# 项目二：汽车电源交流电路的分析与测量

> **所属模块**：基础模块 (Module 1) · **学时**：12 · **任务数**：3

## 项目概述

汽车发电机产生的是 **三相交流电**， 经过整流后向直流电瓶充电。了解汽车交流电路的基本原理， 包括正弳交流电的三要素、 单一元件在交流电路中的特性、 三相交流电路的星形（Y）和三角形（Δ）连接方式， 以及汽车交流发电机的结构和工作原理， 对于正确使用仪器仪表测量交流电路参数和对汽车交流发电机进行拆解与检测至关重要。

### 项目目标

通过本项目的学习， 学生将能够：

- ✅ 了解正弦交流电的概念及三要素（最大值、 角频率、 初相）
- ✅ 明确电阻、 电容和电感在交流电路中的电压电流关系及功率特性
- ✅ 掌握三相交流电路的星形（Y）和三角形（Δ）连接方式及电压电流关系
- ✅ 使用万用表、 示波器等仪器仪表测量交流电压的有效值、 峰峰值、 周期和频率
- ✅ 进行正弳交流电路的分析计算
- ✅ 拆解、 安装和检测汽车交流发电机
- ✅ 识别、 检测二极管， 分析汽车整流电路的工作原理
- ✅ 掌握电气安全防护和触电急救处理

## 相关知识

::: tip 正弳交流电三要素

1. **最大值（峰值）**： 正弳交流电的最大瞬时值，用 $I_m$ 或 $U_m$ 表示
2. **角频率**： $\omega = 2\pi f$， 正弳量单位时间内经历的弧度数
3. **初相位**： $t=0$ 时正弳量所对应的电角度，用 $\phi$ 表示

> 工程上所说的交流电压、 电流的大小， 均是指**有效值**。 如家用电 "220V" 交流电， 其最大值约为 $220 \times \sqrt{2} \approx 311V$。

:::

::: details 三相交流电路

**星形连接 (Y 型)**:
- 相电压与线电压关系： $U_L = \sqrt{3} \cdot U_p$
- 线电流等于相电流： $I_L = I_p$
- 中线用于不对称负载时， 平衡各相电压

**三角形连接 (Δ 型)**:
- 线电压等于相电压： $U_L = U_p$
- 线电流与相电流关系： $I_L = \sqrt{3} \cdot I_p$

:::

::: details 汽车交流发电机工作原理

汽车交流发电机通过 **电磁感应** 原理工作：

1. 转子带动磁场旋转， 在 stator 固定子绕组中切割磁力线
2. 三相绕组对称分布， 产生三相对称交流电动势
3. 整流器将交流电转换为直流电， 给电瓶充电
4. 调磁电路控制输出电压的大小

:::
