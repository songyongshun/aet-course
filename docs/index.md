# 汽车电工电子技术

## 课程概览

本课程是高职汽车电子技术专业的专业基础课程，面向汽车电子技术、汽车智能技术、新能源汽车技术等专业。课程围绕 **6 个项目 → 15 个任务** 的层级组织，通过 **“基础 → 关键 → 数字 → 高压”** 四个递进模块，系统培养学生的电工电子技术基础知识、电路分析能力和实践操作技能。

### 课程目标

- **知识目标**：掌握电路基本物理量及分析方法；理解磁场、磁路特性；掌握交流电路、半导体器件、数字电路的原理；了解新能源汽车高压安全防护。
- **能力目标**：使用仪表测量电路物理量；识别、拆装、检测汽车电路元器件；识读、分析、绘制汽车电路图；设计简单电路；安全用电。
- **素质目标**：培养科学精神、安全意识、环保意识和工匠精神；树立职业理想和使命担当。
