## 通用教学环节

各教案均遵循 **"任务导入 → 理论讲解 → 实践操作 → 课堂小结 → 总结反思"** 的教学流程：

1. **任务导入**： 以汽车真实故障案例或维修情境引入学习任务
2. **理论讲解**： 采用 "结构 → 原理 → 参数" 递进式讲解， 配合动画/仿真演示
3. **实践操作**： 分组完成 "基础层 → 进阶层 → 综合层" 三级任务
4. **课堂小结**： 回顾知识脉络， 强调安全操作规范
5. **总结反思**： 过程性评价 (自评-互评-师评)， 融入 7S 管理要求

| 项目四 | 晶体管检测、 放大电路静态/动态分析 | 微变等效电路、 交直流叠加 |
| 项目五 | 逻辑门功能、 555 电路原理 | 数制转换、 卡诺图化简 |
| 项目六 | 高压部件识别、 安全防护用具使用 | 高压安全意识培养、 实车操作规范 |
